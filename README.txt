RUBEN WIKI PROTOTYPE

Open index.html in any browser.

Structure:
- index.html                  homepage
- style.css                   all site styling
- graphic-design/             category + project pages
- video-production/           category
- ux-design/                  category + sample case-study page
- other-projects/             category
- categories/                 category index
- notes/                      notes index
- about/                      biography
- images/                     four temporary square portal images

No JavaScript, build step, npm, Nuxt or terminal is required.
You can upload this folder directly to a static host.
